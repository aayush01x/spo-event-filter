# spo-event-filter

LHC booking site, but only the SPO / placement stuff.

## install

1. get [Tampermonkey](https://www.tampermonkey.net/)
2. install [this script](https://raw.githubusercontent.com/aayush01x/spo-event-filter/main/spo-event-filter.user.js)
3. go to http://172.26.131.13/LHC/ (campus wifi only)
4. click **Placements**, bottom right

## tips

- bookmark `http://172.26.131.13/LHC/#spo` to open straight into it
- `/` search, `esc` close
